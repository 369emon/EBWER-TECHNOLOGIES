## Website

If `index.html` is included in the repository root, preview the website by opening it in a browser.

### Deploy with GitHub Pages

1. Push the website files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch and folder containing `index.html` (commonly `main` and `/(root)`).
5. Save and wait for GitHub Pages to publish the site.

Other static hosting options include Netlify and Cloudflare Pages.
